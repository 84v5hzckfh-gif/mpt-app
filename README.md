# MPT

Lege web-app (offline) voor het MPT-trainingsprogramma.

- `./` – marinier: rooster, lessen loggen, uitslagen, inleveren.
- `./instructeur/` – instructeurs: groepen (met tabblad Les: aanwezigheid en doelen per les), logs, bestanden maken.
- `./dashboard/` – dashboard voor de pc: alle groepen naast elkaar.

Deze repo bevat **geen gegevens**: geen roosters, uitslagen, logs, wachtwoorden of persoonsgegevens.
Alle gegevens blijven versleuteld op het toestel van de gebruiker; de app stuurt niets naar een server.
